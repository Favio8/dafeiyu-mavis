# 本机试用 Mavis

在仓库根目录双击 **run.bat**。它使用本项目已锁定的 `.venv` 启动独立Mavis，打开桌宠和控制中心。当前是本机便携源码试用版，需要保留项目目录与本地环境；不要以管理员身份运行。

试用数据放在项目内 `.mavis-local/DaFeiYuMavis/`，已排除Git；Key仍只读Windows凭据库。系统默认数据目录启动时遇到WinError 17，便携入口绕开该本机写入问题，不搬动或覆盖原目录。若直接运行 `python -m assistant`，仍使用系统默认数据目录。

## 开始使用

1. 在控制中心查看概览、任务记录、模型与语音状态。默认模型为 `deepseek-flash`，本机已有Windows凭据无需重录；不要把Key填入任务输入框。
2. 当前没有麦克风，可先使用文字备用入口。若要控制电脑，在权限页打开本次会话的受限授权。支持 `打开记事本`，随后对这次新建空白草稿使用 `输入：你好`（最多16个单行BMP字符）。已有文档不接管，也不保存或覆盖文件。
3. 需要中断时按 **Ctrl+Alt+F12**，或点击控制中心/托盘中的停止入口。停止后需明确复位，再开始新任务。
4. 任务记录来自实际事件与数据库，包含审批、动作和结果验证；“未验证/失败”会保留原因。模型说完成不会直接成为成功记录。
5. 关闭控制中心会收到隐藏提示，可从托盘重新打开；使用托盘“退出”结束桌宠和助手。

语音的本地唤醒、识别和TTS入口已接入；连接麦克风后再按实际使用反馈调整。当前无麦克风，不把合成回放当真人语音已验证。
