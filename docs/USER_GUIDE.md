# DaFeiYu Mavis 0.1.0 使用说明

这是独立Windows桌宠的评估版本。版本号不代表完整PRD或发布Gate已通过，真实结果见交付目录的RELEASE_VALIDATION与RELEASE_GATE。

## 安装与启动

运行 `DaFeiYu-Mavis-0.1.0-win-x64-setup.exe`，按当前用户安装，无需管理员权限。选择程序目录和数据目录；若提示数据目录无法保存设置，选择其他盘的可写目录。不会自动迁移、覆盖旧桌宠或已有Mavis数据。

安装后从开始菜单启动DaFeiYu Mavis。便携版须解压整个zip后运行DaFeiYuMavis.exe，不能单独复制exe；便携数据保存在解压目录的data/DaFeiYuMavis。程序不依赖Python、DSH、Codex或开发者venv。

## 模型与语音

默认模型 `deepseek-flash`。在模型页使用密码输入框配置API Key，保存到Windows凭据库；不要在聊天、任务框、配置文件或日志里粘贴Key。连接/工具探针发送固定短标记，不发送屏幕或用户文件。

语音需要麦克风及本地KWS/VAD/ASR模型，初始关闭。权重不随安装包分发，可在语音页下载固定版本或导入已校验的本地目录，详见[模型包说明](MODEL_PACKS.md)。本机无麦克风，真人连续语音、防自唤醒与设备释放尚待验证。

## 当前电脑操作范围

当前实现只允许明确授权后的记事本操作：`打开记事本`，随后对本次新建空白草稿 `输入：你好`（最多16个单行BMP字符）。已有用户文档不接管，不保存或覆盖文件。通用浏览器、文件保存、视觉操作与完整自然语言执行仍有未完成部分，不要把它当成已完成的通用电脑Agent。

开启受限控制前，按界面显示的急停热键做物理测试、明确复位，再允许本次会话的记事本操作。每次动作经过本地网关；只有结果验证通过才显示成功。文字输入是备用入口。

## 停止、记录与退出

默认急停为Ctrl+Alt+F12，控制中心及托盘也有停止入口。停止立即撤销后续派发；已发生的动作不声称回滚。复位是新的明确操作，不自动恢复旧任务。

任务记录来自实际数据库，包含目标、动作、审批、验证与错误。未知费用显示未提供。关闭控制中心会隐藏，可从托盘重新打开；托盘“退出”结束助手和桌宠。

卸载仅移除已安装程序，保留数据目录、备份和Windows凭据。可以先通过数据管理页导出/清理应用记录；不会自动删除用户文件。升级前保留生成的备份，回退需使用对应旧版本程序和兼容数据副本，不能保证任意未来版本可向后兼容。

## 已知限制

当前仅在列明的本机Windows x64环境检查。干净虚拟机、其他Windows构建、ARM、RDP、混合DPI及实际麦克风未测项保持待验证；管理员窗口不接管。权限网关不等于对恶意本机程序的强沙箱。素材、Qt/FFmpeg和模型保留独立许可，不是全产品统一MIT或商业授权。
