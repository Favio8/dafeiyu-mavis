# Mavis 控制中心、图标与边缘流光

日期：2026-11-02。用户已确认原生 Qt、屏幕四周流光/中央透明、抽象 AI 核心与 M 字形。此次只改呈现层及提交事件的只读呈现接线，未提升 M2 能力验收状态。

## 设计与复用

- 对照用户提供的 CC Switch 截图，采用 Swiss 方向：白色内容区、`#F7F7F8` 侧栏、细线边界、`#002FA7` 主色。系统无衬线字体配中文回退；保留红色急停语义。八个功能域、真实任务记录、一次性审批入口保持原有含义。
- GitHub 调研：[CC Switch](https://github.com/farion1231/cc-switch/blob/main/package.json) 为 Tauri/React/Lucide，调研时仍在更新；借鉴信息层级，不迁移其运行时。[Lucide](https://github.com/lucide-icons/lucide/blob/main/LICENSE) 许可已读；本轮没有引入它的依赖或素材，继续复用上游 `vector_widget_icon`。
- 复用 `SettingRow`、`SettingsCard`、原始桌宠动画、气泡与托盘桥。导航 18px 矢量图标，选中蓝色，动作图标带文字和可访问名称。
- 原创 Mavis 标志：蓝色开放环、白色 M、青色核心点。交付 SVG、8 种 PNG 尺寸以及含 7 种尺寸的 ICO。控制中心和 core-only 托盘已使用；完整桌宠托盘保留角色图标。尚未重新打包安装器。
- 操作提示开关只存本次运行，默认开；它不授予电脑操作权限，不写配置/数据库。遵守 Windows 客户区动画偏好，关闭系统动画时保持静态边缘。

## 执行边界

`TaskService` 提交后 → `Controller._published` → `ControlActivity` → Qt 边缘窗口。

仅 live 任务在权限网关提交 `tool.started` 后进入发光的执行阶段；同一执行阶段的原语间保持连续，审批、暂停、验证、终态和新任务/代数清除状态。测试任务不会自动发光。用户点「预览流光 · 4 秒」只触发明确标注的本地视觉预览。

每屏一个顶置透明窗口，屏幕中央从原生窗口 region 排除；使用 `WindowTransparentForInput`、`WindowDoesNotAcceptFocus` 和 `WA_ShowWithoutActivating`。不含按钮、网页、截图或工具指令。GUI 线程每 75ms 读取状态，发光时至多约 30fps；隐藏时停止动画计时器。急停锁存独立于 Qt；GUI 忙时画面撤下可能延后，但不会阻塞急停撤权。此次没有绕过或修改权限网关、许可、原生输入后端和结果验证。

## 验收限制与复现

- 以上原生查询验证了焦点和命中行为；本轮没有注入真实鼠标/键盘，也没有重跑 Notepad 输入任务或物理急停。完整桌宠 smoke 中点击是 Qt 自有控件调用，不算新的 Computer Use 成功证据。
- 多屏热插拔已实现监听，混合系统 DPI、多显示器和 macOS/Linux 实机尚未验证。1.5 是 Qt 缩放因子，不等于系统 DPI 矩阵完成。
- 深色样式用于兼容性验收；默认仍为用户指定的浅色，未增加持久主题设置。
- 总仓库测试未重新全跑；之前的上游 Qt fatal abort/超时及 lint 问题仍列在 M0/M1 报告。不能声称全仓门禁已通过。
- 无 API 调用、无凭据读写、无全盘扫描、无 shell 工具授权。完整视觉取屏路径尚未接入；未来需处理执行提示层的截图排除策略。
- 本轮不改变 DEV-015～023 的未完成状态，也不代表语音唤醒或产品打包完成。
